================================================================
              部署步骤 (三选一)
================================================================

【快速部署】使用自动脚本
   1. 上传: dist.zip, nginx.conf, deploy.sh
   2. chmod +x deploy.sh
   3. sudo ./deploy.sh
   ✓ 自动备份、自动配置、自动重启

【手动部署】逐步操作
   1. unzip dist.zip -d /usr/share/nginx/html/
   2. cp nginx.conf /etc/nginx/conf.d/vben-admin.conf
   3. nginx -t
   4. systemctl restart nginx
   ✓ 完全掌控部署过程

【Docker部署】容器化
   1. docker build -t vben-admin .
   2. docker run -d -p 80:80 vben-admin
   或: docker-compose up -d
   ✓ 隔离环境、易于管理

================================================================
              常见问题
================================================================

Q1: 404错误怎么办?
A:  检查nginx配置文件中的root路径和try_files配置

Q2: 如何修改端口?
A:  编辑nginx.conf中的 listen 80; 改为其他端口

Q3: 如何启用HTTPS?
A:  参考DEPLOY.md中的SSL配置章节

Q4: 接口跨域问题?
A:  在nginx.conf中添加反向代理或CORS头

Q5: 如何更新版本?
A:  备份当前版本 -> 上传新dist.zip -> 解压覆盖 -> 重启nginx
