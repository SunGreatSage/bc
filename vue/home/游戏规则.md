## 系统概述

本系统是一个六合彩投注管理平台，主要用于：

1. **代理收单**：代理帮客户下注，系统记录谁投了多少钱
2. **自动结算**：开奖后系统自动计算中奖金额
3. **后台管理**：查看谁压中了、盈亏统计

### 业务流程

```
总管理 → 给代理开额度 → 代理收到客户的钱 → 代理帮客户下注 → 开奖 → 系统自动结算
                                    ↓
                              写备注记录是哪个客户
```

## 基础信息

### 开奖号码

每期开出 **7个号码**：
- **平码**：前6个号码（第1-6球）
- **特码**：第7个号码（特别号）

号码范围：**01-49**

### 生肖

12生肖：鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪

**生肖年度规则**：
- 当年生肖对应 5 个号码（1, 13, 25, 37, 49）
- 其他生肖对应 4 个号码
- 每年生肖向前移动一位

### 投注限制

- 投注金额必须为**整数**
- 最小投注：1元
- 单次最多：100注

## 玩法规则

### 1. 特码

**玩法说明**：投注一个号码，猜测开奖的第7球（特码）是什么号码。

| 项目 | 说明 |
|------|------|
| 投注内容 | 01-49 任选一个号码 |
| 中奖条件 | 所选号码 = 开奖特码 |
| 参考赔率 | 01-48号：42倍，49号：47倍 |

**示例**：
- 投注：特码 08，金额 100元
- 开奖特码：08
- 中奖金额：100 × 42 = 4200元

---

### 2. 平码

**玩法说明**：投注一个号码，猜测开奖的前6球（平码）中是否包含该号码。

| 项目 | 说明 |
|------|------|
| 投注内容 | 01-49 任选一个号码 |
| 中奖条件 | 所选号码出现在前6球中的任意一球 |
| 参考赔率 | 约 8倍 |

**示例**：
- 投注：平码 26，金额 100元
- 开奖号码：03, 15, **26**, 33, 41, 47 + 特码08
- 中奖金额：100 × 8 = 800元

---

### 3. 特肖

**玩法说明**：投注一个生肖，猜测开奖特码所属的生肖。

| 项目 | 说明 |
|------|------|
| 投注内容 | 12生肖任选一个 |
| 中奖条件 | 开奖特码所属生肖 = 所选生肖 |
| 参考赔率 | 约 12倍 |

**示例**（2025年蛇年）：
- 投注：特肖 蛇，金额 100元
- 开奖特码：13（13号属蛇）
- 中奖金额：100 × 12 = 1200元

---

### 4. 六肖

**玩法说明**：投注6个生肖，猜测开奖的7个号码（6个平码+1个特码）所属的生肖是否全部在所选范围内。

| 项目 | 说明 |
|------|------|
| 投注内容 | 选择6个生肖 |
| 中奖条件 | 开奖7个号码的生肖全部在所选的6个生肖中 |
| 参考赔率 | 约 1.97倍 |
| 特殊规则 | 开出49号视为**和局**，退还投注金额 |

**示例**（2025年）：
- 投注：六肖 鼠-牛-虎-兔-龙-蛇，金额 100元
- 开奖号码所属生肖：鼠、牛、虎、虎、龙、蛇、蛇
- 中奖金额：100 × 1.97 = 197元

## 开奖与结算

### 时间节点

| 阶段 | 时间 | 说明 |
|------|------|------|
| 开盘 | 根据x_kj表opentime | 开始接受投注 |
| 封盘 | 根据x_kj表closetime（提前5分钟） | 停止接受投注 |
| 开奖 | 根据x_kj表kjtime | 公布开奖号码 |
| 结算 | 开奖后自动 | 系统自动计算中奖 |

### 结算规则

1. **中奖**：投注金额 × 赔率 = 中奖金额
2. **未中奖**：投注金额扣除，不返还
3. **和局**（仅限连肖玩法开出49号）：退还投注金额

### 投注记录字段

| 字段 | 说明 |
|------|------|
| z=9 | 未开奖 |
| z=1 | 已中奖 |
| z=0 | 未中奖 |

## 代理与账户体系

### 账户层级

```
总管理（系统管理员）
    ↓
代理（帮客户收单）
    ↓
客户（实际投注人）
```

### 代理模式

1. **总管理给代理开额度**：设定代理可用的信用额度
2. **代理收单**：收到客户的钱后，代理在系统中帮客户下注
3. **备注记录**：通过备注标记是哪个客户的投注
4. **结算**：
   - 中奖：系统自动计算，代理把钱给客户
   - 未中：投注金额归系统

### 账户字段说明

| 字段 | 说明 |
|------|------|
| kmaxmoney | 信用额度上限 |
| kmoney | 可用余额（可投注金额） |
| sy | 上水/返点 |
| jzkmoney | 冻结金额 |

### 查看中奖情况

后台提供以下功能：
- **即时注单**：查看当前期所有投注
- **报表统计**：查看盈亏汇总
- **用户管理**：查看每个代理/客户的投注明细
