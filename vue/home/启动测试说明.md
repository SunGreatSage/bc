## 🔧 已完成的配置

### 1. **前端代理配置** ✅

**文件**: `vite.config.js`

```javascript
server: {
  port: 3000,
  host: 'localhost',
  open: true,
  cors: true,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',  // PHP 后端地址
      changeOrigin: true,
      secure: false,
    },
  },
}
```

**说明**:
- 前端运行在 `http://localhost:3000`
- 所有 `/api` 请求会被代理到 `http://localhost:8000`
- 解决了 CORS 跨域问题

---

### 2. **环境变量配置** ✅

**文件**: `.env.development`

```ini
# API Configuration
# 使用相对路径，通过 Vite 代理转发到后端
VITE_API_BASE_URL=
VITE_API_TIMEOUT=10000
```

**说明**:
- `VITE_API_BASE_URL` 设置为空，使用相对路径
- Axios 会自动使用相对路径 `/api/...`
- Vite 代理会将请求转发到 `http://localhost:8000`

## 🚀 启动步骤

### 步骤 1: 启动后端服务

```bash
# 进入 server 目录
cd E:\Code\Php\bc\server

# 启动 ThinkPHP 开发服务器（端口 8000）
php think run -p 8000
```

**验证后端启动成功**:
```bash
# 访问测试
curl http://localhost:8000
```

---

### 步骤 2: 启动前端服务

```bash
# 进入前端目录
cd E:\Code\Php\bc\vue\home

# 启动开发服务器（端口 3000）
```

**验证前端启动成功**:

## 🐛 常见问题

### Q1: 前端显示 "Network Error"

**原因**: 后端服务未启动

**解决**:
```bash
cd E:\Code\Php\bc\server
php think run -p 8000
```

---

### Q2: 前端显示 "CORS policy" 错误

**原因**: 前端服务未重启

**解决**:
1. 停止前端服务（Ctrl+C）
2. 重新启动 `npm run dev`

---

### Q3: 接口返回 404

**原因**: 路由配置问题

**解决**: 检查后端路由文件

---

### Q4: 登录后没有数据

**原因**: 数据库没有测试数据

**解决**: 执行 S 插入测试数据（已完成）
