## ⚠️ 常见问题排查

### 问题1: 请求没有 plate_code 参数

**检查**:
```javascript
// Console中执行
console.log('当前盘口:', localStorage.getItem('selectedPlateCode'))
```

**原因**:
- localStorage 没有设置
- getSelectedPlateCode() 函数有问题
- API调用时没有传递参数

**解决**:
```javascript
// 手动设置
localStorage.setItem('selectedPlateCode', 'B')
// 刷新页面
location.reload()
```

### 问题2: 后端返回所有盘口的数据

**检查**:
- Network标签查看请求是否包含 `plate_code`
- 查看后端响应的数据

**原因**:
- 后端接口不支持盘口参数
- 后端SQL查询没有WHERE条件

**解决**:
需要修改后端代码,添加盘口筛选:

```php
// 后端需要添加
$plateCode = $this->request->param('plate_code', '');
if (!empty($plateCode)) {
    $where[] = ['pan_type', '=', $plateCode];
}
```

### 问题3: 切换盘口后数据没有刷新

**检查**:
- Console是否有盘口切换日志
- 事件监听是否正常

**原因**:
- 事件没有触发
- 事件监听没有注册

**解决**:
```javascript
// 手动触发测试
window.dispatchEvent(new CustomEvent('plateChanged', {
  detail: { plateCode: 'C' }
}))
```
